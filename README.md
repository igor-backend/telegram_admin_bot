# Telegram-бот для модерации чатов

## Функции:
- [ ] регистрация в чате через решение <b>капчи</b>;
- [ ] дополнительная <b>модерация</b> при регистрации <b>для подозрительных аккаунтов</b> (например, с точкой в качестве имени и без аватара);
- [ ] отправка <b>приветственного сообщения</b> для новых участников;
- [ ] отправка <b>правил чата</b>;
- [ ] <b>удаление сообщений, содержащих ссылки</b> (с возможностью заполнить белый список пользователей и белый список доменов);
- [ ] автоматическое <b>удаление старых сообщений</b> от указанных пользователей (например, если нужно периодически чистить чат от сообщений служебных ботов);
- [ ] <b>удаление дубликатов сообщений</b> (для защиты от очевидного спама);
- [ ] <b>ограничение отправки сообщений по расписанию</b> (например, ночью);
- [ ] генерация <b>статистики по пользователям и их активности</b> (например, самые активные пользователи за период);
- [ ] отправка <b>администратору</b> в личный чат <b>сводной статистики</b> за день (например, количество регистраций и количество отписок).
